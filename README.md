# Margin · YouTube 学习库

当前首版面向英文用户：收藏 YouTube 知识视频、读字幕、划线、写笔记，再从个人书架找回学习记录。Margin 是暂定界面名称。工程沿用 transcript-studio 目录，使用 React、Hono、Cloudflare Workers、D1、R2 和 Queues。

当前功能和上线配置见 [学习库说明](docs/learning-launch.md)。下方“转录功能”记录之前的转录模块，保留在 `/app`，不是新首页的产品范围。

## 本地运行

需要 Node.js 24、npm、Python 3 和 yt-dlp。本工程已安装依赖；新机器先运行 `npm ci`。

```bash
npm start
```

在本工程目录执行。启动脚本会准备未纳入版本管理的 `.dev.vars`，生成本地服务密钥，构建前端、执行本地 D1 迁移，再启动网站和字幕服务，打开 `http://127.0.0.1:5178`。若 5178 端口已占用，会提示检查已有服务。

首页点击 **Open local preview** 进入可恢复的本地预览账户。粘贴 YouTube 链接后取得可用字幕；选中文字可以就地批注或向 AI 提问。数据保存在本地模拟的 D1/R2 中，不是浏览器临时演示数据。DeepSeek 已按用户授权在本地配置并验证，付款关闭。

需开发热更新时，分别启动 `npm run dev:worker` 和 `npm run dev`。Vite 使用 5178，代理 API 到 8787；不要同时运行 `npm start`。

## 转录功能（旧模块）

- YouTube / X 链接白名单、标准化、本人任务去重、时长预检与报价确认。
- Supadata 原字幕与生成适配器；YouTube 无字幕时回退生成，X 与上传直接生成。未验证时间戳的结果只开放文字导出。
- 全站 2 个活跃任务、每人 1 个；异步供应商任务持续占用名额，等待任务保存于 D1。
- SQL 原子分钟预留、交付结算、失败释放、付款入账；持久 Outbox 与定时扫描。
- 提交超时停止重提；状态未知超过 24 小时退回用户预留，仍保留供应商名额等待人工核实。
- 一次性邮箱登录链接、HttpOnly 会话、同源请求检查、预检限流。
- 私有 R2 上传、生产签名直传、不可变副本、服务端 ffprobe 格式/音轨/时长探测、限时 GET/HEAD/Range 读取。
- Creem 收银台和签名回调；按事件和订单防止重复充值；退款/争议撤销可用分钟并冻结账号等待核查。
- 原媒体 24 小时、稿件 30 天保留与定时删除；完成邮件独立重试，不重做转录。

## 验证

```bash
npm run verify
```

类型检查、实际 SQLite 账务/并发测试、供应商边界测试和前端构建。自动化测试使用模拟外部服务，不代表真实 Supadata、Resend、Creem 验收。浏览器本地样例流程已完成；真实跨平台获取与识别质量需要账户配置后实测。

正式开通所需配置、限制与人工操作见 [上线准备](docs/launch.md)。

## GitHub 与版本管理

在 TRAE 中单独打开 `transcript-studio` 文件夹，左侧“源代码管理”可以查看改动、创建提交、切换分支和同步 GitHub。日常修改先在新分支完成，运行 `npm run verify`，检查提交内容后再推送。

仓库只保存源码、配置样例和项目文档。`.dev.vars`、`.env` 及其本地变体、私钥文件、依赖、构建产物、`.wrangler` 数据库与本地上传目录均已忽略。真实 API key 保留在本机 `.dev.vars`，新机器按 `.dev.vars.example` 配置；生产密钥使用 `wrangler secret put` 设置。

`.gitignore` 不会识别写进源码的密钥。每次提交前都应检查差异，日志和截图也要确认没有凭证。不要用 `git add -f` 强行加入密钥文件；私有仓库同样需要遵守这些规则。本地书架、字幕、笔记和划线数据不随 Git 上传，需另行备份。
