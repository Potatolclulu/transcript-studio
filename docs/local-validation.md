# 本地验证与当前功能

2026 年 10 月 31 日。入口：<http://127.0.0.1:5178>。

## 本次已跑通

从网页点击真实测试按钮，经本地账户、分钟预留、任务队列、豆包录音识别、结果保存、文字阅读与搜索，直到字幕导出和分钟结算，已完成一次真实验证。

音频是豆包控制台公开的 6.312 秒示例。每个新任务实际调用语音接口，没有复用固定文字冒充识别。网站任务和供应商任务均已核对；具体任务 ID 不写入共享文档。

真实结果：“刚刚还在想你怎么还不来找我聊天，你就来了，真是心有灵犀啊。”供应商返回分句时间为 0.480–5.880 秒。浏览器搜索“心有灵犀”出现高亮，选择 SRT 并点击导出。四种导出接口另行验证，TXT、Markdown、SRT 和 VTT 均包含真实结果。

测试账户一次领取 2 分钟。首次本地测试因 Workers 中的 fetch 调用方式错误，没有触达供应商；经直接查询任务不存在，已停止并退还预留分钟。修复后第二个任务成功，最终可用 1 分钟、预留 0 分钟。重复提交相同测试返回原任务，余额不再变化；重新登录也不会补发额度。

`npm run verify` 已通过：22 项测试、类型检查与构建。测试覆盖状态码、真实时间戳解析、额度与并发错误区分、超时后只查任务不重提、失败退分钟、保存结果恢复及开发入口的生产禁用。另有本地 workerd 浏览器实测；正式云端语音链路仍需单独验收。

## 你现在可以怎样试

1. 打开首页，点击顶部 **Run real ASR test · 1 min**。自动进入本地测试账户，不需要配置邮箱或支付。
2. 已成功跑过相同音频时，会直接打开原结果，避免重复扣分钟。
3. 搜索“心有灵犀”，检查匹配段落和高亮。
4. 选择 TXT、Markdown、SRT 或 VTT，点击 **Export**。
5. 点击左下角 **Your account** 查看分钟预留、返还及结算记录；刷新页面仍能找回结果。

**Try a sample** 是另一条体验路径，只打开固定英文示例，使用样例账户的 12 分钟，无真实语音费用。未登录公众访客目前没有真实转录免费额度；本地测试按钮只在开发环境启用，不代表开放公众试用。

豆包需要音频文件的可访问地址。YouTube/X 的网页地址不能直接交给录音识别；还需服务端获取音频。登录本网站不会传递 YouTube/X 的登录状态。

豆包也不能读取 localhost 上传地址。上传链路需要限时私有媒体地址或受限通道、探测服务，以及相应转码。本次只验证公开官方音频，没有宣称用户上传或平台视频已跑通。

## 凭据与上线

本地 Key 保存在忽略提交的 `.dev.vars`，变量为 `DOUBAO_API_KEY`；资源标识为 `DOUBAO_RESOURCE_ID=volc.seedasr.auc`。部署时把 Key 存为 Cloudflare Secret，后端通过环境绑定读取；不要写入前端或普通公开 vars。本次没有上传 Key 或部署新版。

本地 `LOCAL_ASR_TEST_ENABLED=true`、`DAILY_BUDGET_CENTS=20`。2 美分/分钟只是保守预算预留参数，不是已核验的供应商售价。普通转录入口和收款仍关闭；生产配置关闭开发测试。

配置凭据时应检查复制和 Markdown 转义是否改变了原值。命令里的 URL 不应带反引号；凭据仅保存在本地配置或服务端 Secret 中。

下一步先跑自有文件上传及可访问媒体地址，再实现并实测 YouTube/X 音频获取，最后验收邮件和支付。尚未完成平台获取稳定性、长音频质量与真实费用核算。

接口依据：[豆包录音文件识别标准版](https://www.volcengine.com/docs/6561/1354868)、[Cloudflare Secrets](https://developers.cloudflare.com/workers/configuration/secrets/)。
