## 并发决定

初始全站最多 2 个活跃任务，单用户最多 1 个；都由服务端执行。等待任务持久保存，以数据库的原子条件更新争抢名额。队列并发控制仅限制消费者执行数，不替代跨异步供应商任务的全站名额。

成功交付前分钟为预留状态。重复点击、队列再次投递、付款事件再次发送不得增加费用。供应商提交结果未知时占用名额并停止自动重提，防止原任务还在运行时又启动一个任务。

生产配置默认关闭转录与收款，日预算为零。只有真实服务配置、条款与样本验收完成后才开启。测试使用明确的样例输入，不给任意 URL 返回伪造转录稿。
