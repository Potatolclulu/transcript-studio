# 哔哩哔哩与小宇宙接入

用户已确认接入两个平台。沿用当前书架、阅读页和笔记体系；先完成本地真实使用流程，生产服务按文末条件配置。

## 已核验的来源

- 小宇宙公开单集样例：约 78 分钟，公开音频支持 HTTP Range。页面标记启用了逐字稿，但公开数据只给出音频标识，没有取得带时间戳的正文。
- 哔哩哔哩公开视频样例：约 15 分钟，公开音轨可读取，元数据包含 6 个章节。未登录状态下未取得字幕。
- 短音频已成功通过豆包极速版直接上传识别，返回带时间戳的分句。服务需配置具备 `volc.bigasr.auc_turbo` 权限的密钥。
- 官方接口依据：https://www.volcengine.com/docs/6561/1631584 。极速版支持 MP3/WAV/OGG OPUS，以及 `audio.data`；标准版依赖公网音频 URL，不能直接读取本机地址。

## 方案选择

采用“平台解析器 + 持久后台任务 + 可控播放器”。相比仅嵌入原站播放器，这种方式能直接取得播放时间并跳转，保留字幕自动跟随和笔记定位；相比浏览器端获取媒体，服务端处理更容易限制来源、文件大小和密钥访问。

YouTube 继续沿用当前字幕获取和官方播放器。小宇宙使用音频播放器。B 站使用公开视频与音轨合成的 MP4。浏览器通过同源、校验账户归属的媒体接口播放，不接触服务密钥或供应商凭证。

## 数据与接口

- 增加平台、来源标识、媒体类型、媒体缓存标识和导入进度字段。迁移为已有 YouTube 项目补默认值，保留原 ID、字幕、播放位置和所有笔记。
- 统一解析用户链接，只接受规定平台的单条公开内容。去除分享跟踪参数；B 站保留明确的分 P 选择。拒绝凭证 URL、任意主机、直播和受限内容。
- 保留当前字幕服务接口，另增加非 YouTube 异步请求协议。首次请求只创建任务并返回；后续读取持久任务状态。重复请求复用任务和结果。
- Worker 对后台结果做结构、大小和时间轴校验，再保存字幕与搜索索引。后台未完成时展示获取音频、准备视频、转录分段等进度。
- 已保存字幕的首个版本继续作为笔记锚点；重试和切换视图不能覆盖旧笔记来源。

## 后台媒体处理

- 解析器构造已知平台 URL，通过 yt-dlp 获取 B 站元数据与可用字幕，通过公开页面获取小宇宙节目元数据。
- 有可用字幕时优先保留字幕。没有字幕时，先在本地下载并转为单声道 MP3，再分段调用已验证的豆包极速版。带时间偏移合并分句，保证时间轴单调、句子不越界。
- 获取、转换和识别在 Python 服务中运行。任务及已完成的分段写入被 Git 忽略的本地缓存；已完成识别不重复付费。未确认结果的请求标记失败，由用户明确重试。
- 限制并发、单文件大小、总缓存体积及每日识别分钟数。读取密钥时不输出值，不将媒体、任务状态或密钥写入源码目录中的可提交文件。
- 媒体服务支持 GET/HEAD、Range 和取消读取。Worker 流式转发媒体，不将整个视频读入内存。所有媒体接口均须验证账户归属。

## 阅读体验

- 输入入口说明支持 YouTube、bilibili 和 Xiaoyuzhou，书架和阅读页显示正确来源。
- 统一播放器的播放时间与 seek 接口。播放、暂停、跳转、章节点击、笔记点击和字幕跟随都使用同一套现有回调。
- 小宇宙展示音频控制条；B 站保留 16:9 视频区域。原站链接始终可打开。
- B 站已有章节可直接复用。没有章节时仍可按需生成。中文原文不自动提交整篇翻译。

## 运行与上线

本地继续使用 `npm start`；后台服务由启动脚本一并启动。默认配置：两个并发任务、最多四个等待或运行任务，单条最长两小时、单文件上限 512 MiB、缓存上限 4096 MiB、每日识别上限 180 分钟。缓存满时停止接受新任务，由服务维护者清理不再使用的媒体；不会自动删除既有笔记。

任务和识别检查点位于被 Git 忽略的 `.wrangler/media-cache`；字幕快照和笔记仍使用 D1/R2。`DOUBAO_API_KEY` 需具备 `volc.bigasr.auc_turbo` 权限。识别分钟数是独立的服务端限额，不使用旧转录模块的用户余额计费。

生产运行需要持续运行的 Python 媒体服务、ffmpeg/ffprobe、yt-dlp、可写的持久缓存目录与 HTTPS 服务地址。`CAPTION_SERVICE_URL` 指向 `/extract`，同一主机同时开放经服务密钥认证的 `/jobs`、`/jobs/:key` 和 `/media/:key`。Worker 继续验证用户与条目归属后转发媒体。服务凭证只放在服务端；真实环境文件与缓存保持不进入 Git。本次完成本地迁移和验收；代码同步 GitHub 不代表已部署生产。
