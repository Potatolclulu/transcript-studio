# 首版本地验证 · 2026-10-31

学习库核心流程已在本地 Cloudflare 运行时和真实浏览器中跑通。数据使用本地模拟的 D1、R2 和 Queues，尚未部署到生产环境。

实测视频：Tim Urban 的 TED 演讲 [Inside the Mind of a Master Procrastinator](https://www.youtube.com/watch?v=arj7oStGLkU)，时长 844 秒。网站取得 315 段英文人工字幕，保留平台原始时间戳，没有调用豆包，也没有扣除转录分钟。

已验证：

- 同一账户重复添加链接，返回同一收藏；另一个账户不能读写或搜索这份资料。
- 从真实字幕圈选、保存划线和笔记，编辑后刷新仍能找回；保存失败不显示成功，旧版本编辑会提示冲突。
- 标签、手动完成状态、正文搜索和跨库笔记搜索可用；搜索结果回到对应视频和记录。
- 未保存笔记离开页面会提示。390 像素宽的手机布局没有横向溢出。
- 真实 YouTube 播放器已连接。点击 `0:32` 的时间标记后播放，实测播放到约 `35.10` 秒、状态为播放中，文字同步高亮第 11 个字幕位置。“跟随播放”可由用户开关。
- 未配置模型时，AI 说明当前不可用，发送按钮关闭，不生成示意答案。随后按用户授权配置 DeepSeek，已在真实英文视频上得到中文回答及 5 条原文引用。
- 选文旁显示“Highlight / Add annotation / Ask AI”；在原段落编辑批注，保存和刷新后仍留在该处。点击高亮可以重新提问，已保存问答可从原文旁恢复。手机布局已验证。

36 项自动化测试、类型检查和构建全部通过。检查覆盖字幕导入不扣费、精确原文锚点、旧字幕快照保留、删除关联数据、导入租约恢复、问题持久保存、预算限制、无效引用拒绝、停止后不发布答案、DeepSeek JSON 参数，以及生产环境关闭本地预览登录。

最终服务重启后，315 段字幕、3 条划线/笔记、标签、完成状态，以及分别保存的播放位置和阅读位置仍然存在。首页由启动脚本打开，`Open local preview` 可进入同一份预览书架。

记录当前存于 `transcript-studio/.wrangler/state/v3/`：笔记、问答和位置在本地 D1，字幕快照在本地 R2。不是浏览器 localStorage；清除这份开发目录会丢失本地记录。正式部署后应使用 Cloudflare D1/R2，并另外迁移现有本地记录。

生产仍需配置独立 HTTPS 字幕服务、正式邮件登录和生产模型密钥。当前证据只覆盖本机样本，不能据此承诺全部 YouTube 链接或生产来源获取的成功率。配置步骤见 [学习库运行说明](learning-launch.md)。

## 长视频字幕导入修复

实测 [Deep Dive into LLMs like ChatGPT](https://www.youtube.com/watch?v=7xTGNNLPyMI)，时长 12,683 秒（3:31:23）。原始英文 JSON3 字幕已经下载成功，大小为 4,342,829 字节，但超过了原先共用的 4 MiB 数据限制，被误报为“Captions could not be downloaded”。

在 `probe/captions.py` 中将原始字幕文件的上限单独设为 16 MiB，元数据及整理后服务响应仍保持 4 MiB 上限。超过原始文件上限时明确提示大小问题，缺少下载文件时仍提示下载失败。

修复后完整提取 5,761 段英文自动字幕，整理后的 JSON 为 515,706 字节。字幕服务已重启；原账户中的失败收藏经本地任务队列重新导入，状态为 `ready`，错误已清除，D1 中建立了 481 个正文搜索块。

新增三项 Python 回归测试：超过 4 MiB 的原始字幕可整理为小响应、超过 16 MiB 的文件明确拒绝、缺少字幕文件仍保留下载错误。运行 `python3 -B -m unittest discover -s tests -p captions_test.py -v` 全部通过。

当前安装版本的本地定时事件入口为 `/cdn-cgi/local/scheduled`；`/__scheduled` 在本项目的静态页面配置下返回首页。恢复任务时使用前者触发正常调度。
